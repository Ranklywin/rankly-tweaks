# v1.0.0 validation

[GitHub Actions](https://github.com/Ranklywin/rankly-tweaks/actions) records the
Linux and Windows tests, dependency audit, build, package verification, and checksums.
Windows tests use isolated fixtures and stubbed setters, not live gaming tweaks.

The browser UI was checked for dropdown behavior, keyboard access, both themes,
and sidebar layout. The local real-PC baseline is Windows 10 build 19045.

Game benchmarks and broader Windows 11 hardware testing are still needed.
The executable is unsigned; no universal FPS or ping improvement is promised.
