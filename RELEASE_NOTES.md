# Rankly Tweaks v1.2.1

Play ranked on Rankly, right from the app.

- Free ranked Fortnite Boxfights, Realistics and Zone Wars on rankly.win. Open
  it from the sidebar, the Overview page, or the small invite you can close.
- Light mode is now light everywhere, and the Overview banner shows the current
  Emerald rank emblem.

Already on v1.1.0 or newer? Rankly offers this update in the app. Coming from
v1.0.0? Download **Rankly-Tweaks-1.2.1-setup.exe** and install it once.
Windows 10 21H2+ / Windows 11, x64. Requires administrator access; not yet code-signed.
`SHA256SUMS.txt` is included to verify your download.

Results vary by PC. Review each tweak before applying it.
