# Rankly Tweaks v1.0.0

The first public open-source release of Rankly Tweaks for Windows x64.

- Review individual gaming, graphics, power, storage, input, and network controls.
- Hardware and Windows support checks keep unsupported changes unavailable.
- Original values are backed up locally, writes are verified, and Recovery can
  restore changes in reverse order.
- Custom dropdowns, dark/light themes, and optional background-app management.

Download **Rankly-Tweaks-1.0.0.exe** below. No installation is required. The app
requests administrator access. Compare its SHA-256 hash with `SHA256SUMS.txt`.
The executable is unsigned.

Windows 10 build 19044 or newer and Windows 11 are targeted; x64 only. Individual
controls have additional requirements. The documented real-PC validation baseline
is Windows 10 build 19045; Windows 11 and other hardware need broader validation.
No universal FPS or ping increase is promised. Review power and security tradeoffs.

Backups remain under `%APPDATA%\rankly-tweaks`; preserve that folder. Opening or
scanning the app applies no tweaks. Manual Windows changes and closed app sessions
are outside Recovery.

MIT licensed, with bundled third-party notices. Earlier local development versions
are not previous public releases.
