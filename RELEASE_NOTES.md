# Rankly Tweaks v1.1.0

Rebuilt on Tauri: a 2.5 MB installer instead of a 100 MB app, with in-app updates.

- Performance checkup: flags a monitor below its top refresh rate, memory at base
  speed or in one channel, a monitor on integrated graphics, laptops on battery,
  and missing or old graphics drivers.
- Mouse polling test on the new Input page.
- Variable refresh for more games (Windows VRR option).
- In-app updates, verified by signature before installing.
- Your existing recovery backups carry over.

Download **Rankly-Tweaks-1.1.0-setup.exe** and run it. Coming from v1.0.0?
Install this once; later versions update inside the app.
Windows 10 21H2+ / Windows 11, x64. Requires administrator access; not yet code-signed.
`SHA256SUMS.txt` is included to verify your download.

Results vary by PC. Review each tweak before applying it.
