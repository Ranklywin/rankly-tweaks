# Rankly Tweaks v1.2.0

New advanced tweaks, each backed up in Recovery like the rest.

- NVIDIA driver tweaks for lower input delay and steadier clocks, plus a
  G-SYNC setup that caps FPS just under your refresh rate.
- A fix for flicker or stutter in borderless games.
- Better core scheduling on CPUs with performance and efficiency cores.
- Removed one tweak that Windows Settings already offers; old backups still restore.

Already on v1.1.0? Rankly offers this update in the app. Coming from v1.0.0?
Download **Rankly-Tweaks-1.2.0-setup.exe** and install it once.
Windows 10 21H2+ / Windows 11, x64. Requires administrator access; not yet code-signed.
`SHA256SUMS.txt` is included to verify your download.

Results vary by PC. Review each tweak before applying it.
