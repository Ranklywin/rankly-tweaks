# Changelog

## 1.0.0

First public open-source release. Earlier version numbers in research notes refer
to local development builds, not public releases.

- Windows gaming, graphics, power, input, storage, and network controls with
  per-control explanations, support checks, and review before applying.
- Durable local backups, verified writes, rollback, and recovery after interruption.
- Optional background-app closing with process identity checks.
- Dark and light themes, searchable categories, and custom accessible dropdowns.
- MIT license, bundled third-party notices, pinned dependencies, and GitHub checks.
- Portable x64 executable, package verification, and SHA-256 checksum.

Known limitations: unsigned executable; hardware-dependent results; real-PC
validation baseline is Windows 10 build 19045. See README for details.
